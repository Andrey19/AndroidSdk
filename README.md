# AndroidSdk
Приложение "Android SDK" - 4 задачи


# Задача 1. Навигация между 3 фрагментами

Что сделано:

Router.kt - интерфейс

FragmentRouter.kt - роутер на FragmentManager (без библиотек)

FirstFragment, SecondFragment, ThirdFragment - три экрана с кнопками

Как работает: Роутер переключает фрагменты через replace() + addToBackStack()


# Задача 2. WorkManager

Что сделано:

ChargingWorker.kt - проверяет зарядку и шлет уведомление

Task2Fragment.kt - кнопка для планирования

Как работает: WorkManager с условием setRequiresCharging(true) выполняется один раз при подключении зарядки


# Задача 3. Кастомная View

Что сделано:

FillableRectangleView.kt - прямоугольник, при клике +10% заливки, цвет рандомный

Как работает: При клике увеличивается процент, цвет меняется через Random, при 100% - сброс


# Задача 4. Чат

Что сделано в чате:

ChatMessage.kt - просто моделька сообщения. Там текст, флаг "моё/чужое" и время.

ChatAdapter.kt - адаптер для списка. Сделал два вида ячеек: свои сообщения справа (зеленые), чужие слева (серые). Так понятнее, кто кому пишет.

ChatViewModel.kt - туда сложил список сообщений. Живет дольше, чем экран, поэтому при повороте телефона сообщения не пропадают. Там же метод отправки и имитация ответа.

Task4Fragment.kt - сам экран: поле ввода, кнопка "Отправить", список сообщений. Подписался на LiveData из ViewModel, когда появляется новое сообщение - список сам обновляется.

Почему так:

RecyclerView - стандарт для списков на Android

ViewModel + LiveData - чисто и удобно, данные сами приходят в UI

Два типа ячеек - чтобы визуально разделить свои и чужие сообщения
